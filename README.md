# Sistema Comercial

## Descrição
O Sistema Comercial é um aplicativo mobile desenvolvido para auxiliar pequenos empreendedores no controle de vendas e organização financeira.

Através do aplicativo, o usuário pode:

- Cadastrar novos produtos com controle de estoque.
- Registrar vendas realizadas na loja.
- Visualizar o total vendido por período (hoje, 7 dias, 30 dias e ano).
- Acompanhar gráficos de vendas por período.
- Identificar os 5 produtos mais vendidos.

O sistema foi pensado para substituir o controle manual feito em cadernos ou planilhas simples, trazendo mais organização, praticidade e segurança para o pequeno comércio.

---

## Funcionalidades
- Cadastro de produtos com nome, preço e quantidade em estoque.
- Edição e controle básico de estoque.
- Registro de vendas vinculadas aos produtos.
- Atualização automática dos indicadores no Dashboard.
- Filtro de vendas por período (Hoje, 7 dias, 30 dias, Ano).
- Gráfico de desempenho por período.
- Exibição dos produtos mais vendidos.
- Armazenamento local utilizando SQLite (funciona offline).

## Como Rodar Localmente
1. Certifique-se de ter o Node.js instalado.
2. Instale as dependências do projeto:
npm install
3. Inicie o projeto com:
npx expo start
4. Instale o aplicativo Expo Go no celular.
Escaneie o QR Code exibido no terminal para executar o app no dispositivo.
